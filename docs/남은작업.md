# UBDA 남은 작업 (2026-11-12 기준)

새 대화에서 "UBDA 남은 작업 이어서 하자"라고 하면 여기서부터 시작한다.

## 현재 상태
- 저장소 1개(`ubda-template`)에 기업별 폴더 `companies/<기업>/` 구조. 기업: 삼양식품(samyang), 오뚜기(ottogi)
- 공개 주소: https://ubda-template.onrender.com/ (기업 목록) · `dashboard.html?c=<기업>`
- DART_API_KEY는 Secrets에 등록 완료, Render 연결 완료. 기업을 추가할 때마다 다시 할 필요 없음
- 재무(DART)와 주가(Yahoo)는 자동 수집됨. 평일 16:40 자동 업데이트
