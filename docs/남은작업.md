## 알려진 점
- 삼양식품 2023년 분기 합 ≠ 연간 (약 70만 원 차이): 1분기 값이 이후 보고서에서 재분류됨 → 경고로 표시 중
- 은행 업종은 손익 구조가 달라 수집 계정 추가가 필요 (아직 안 함)
- 크라운제과: 종속회사가 없어 별도 재무제표 기준. 2022·2023 매출−원가−판관비와 영업이익이 0.7억·1.1억 차이(기타영업손익 추정, 원문 확인 전) → 경고
- 해태제과: 2024-05-16 2016~2019 사업보고서 기재정정 공시. 분석 기간(start_year−1) 이전 보고서는 수집·계산에서 제외하도록 수정함
- 두 업데이트 실행이 겹치면 데이터 커밋이 충돌할 수 있어, 나중 실행 결과를 우선하도록 수정함 (2026-11-12)
- 업데이트는 4묶음 동시 실행(run_all.py --shard i/4). DART가 느린 날 기업당 6분까지 걸려 한 번에 돌리면 35분 제한을 넘김 (2026-11-13)
- 이후 보고서가 과거 연도를 재작성한 경우(한온시스템·LG전자·삼성전기·GS리테일 등) KPI의 해당 연도 scope에 "재작성"을 적고 '연결' 합계 검산 대상에서 빼며, 대시보드 연간 매출과 다른 이유를 note에 남김
- [x] 분기 합≠연간: 같은 해 뒤 보고서가 앞 분기를 재작성한 근거(반기·3분기 누적 ≠ 앞 누적+3개월)가 데이터에 있으면 '경고'로 낮추고 근거 숫자를 남김 (GS리테일·한온시스템·삼성전기·롯데쇼핑, 2026-11-13 사용자 결정 A안)
