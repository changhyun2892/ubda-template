# UBDA 남은 작업 (2026-11-12 기준)

새 대화에서 "UBDA 남은 작업 이어서 하자"라고 하면 여기서부터 시작한다.

## 현재 상태
- 저장소 1개(`ubda-template`)에 기업별 폴더 `companies/<기업>/` 구조. 기업: 삼양식품(samyang), 오뚜기(ottogi)
- 공개 주소: https://ubda-template.onrender.com/ (기업 목록) · `dashboard.html?c=<기업>`
- DART_API_KEY는 Secrets에 등록 완료, Render 연결 완료. 기업을 추가할 때마다 다시 할 필요 없음
- 재무(DART)와 주가(Yahoo)는 자동 수집됨. 평일 16:40 자동 업데이트

## 1. 불닭 대시보드에서 빠진 기능 옮기기 (데이터 없이 가능)
원본 `changhyun2892/vuldak-dashboard`의 assets/app.js·screen.html을 **읽기만 하고**, 디자인·구성을 재사용한다. 원본은 수정하지 않는다.
- [ ] 메인 스크린 (어두운 관제 화면, screen.html) — 기업명·지표를 company.json·CSV에서 읽게
- [ ] 기업 비교 — 같은 산업의 기업끼리 선택
- [ ] 데이터 질의 패널 (오른쪽, CSV 계산·사용 행·산식·출처 표시)
- [ ] 편집 모드 (카드 끌어 배치 변경, 브라우저 저장)
- [ ] 연간/분기 전환, 기업·연도 필터
- [ ] DART 자동 업데이트 전용 화면
- [ ] 주가 화면에 사건 표시 (사건 연표 데이터가 생기면)

## 2. 산업 KPI 화면 틀 (데이터가 있으면 표시, 없으면 '미확인')
- [ ] 사업·해외 (제품군 매출, 수출, 해외법인·지역)
- [ ] 생산 (생산능력·가동률)
- [ ] 공급사슬 (원재료 가격·매입처·판매경로)
- [ ] 검색 관심도 (사용자가 Google Trends·네이버 CSV 제공, 판매량 아님)

## 3. 기업별 조사 (AI 초안 + 사람 검토)
- [ ] 오뚜기 산업 KPI 조사 (KIND 사업보고서 원문). 참고: 라면 제조는 관계사 오뚜기라면이 맡고 있어 제품군 매출 해석에 주의
- [ ] 사건 연표, 5가지 관점, 분석 보드 — 기업별 해석 문장

## 4. 3D 뉴런 포털 첫 버전
- [ ] index.html을 3D 화면으로 교체. 데이터는 `companies/index.json`의 graph(nodes/links)를 그대로 사용
- [ ] 노드 클릭 → `dashboard.html?c=<기업>`. 라면 카테고리 기업을 3개 이상(농심 추가)으로 늘린 뒤 시작하는 것을 권장
