# 기업 토론 생성 절차 (API 없이, 요청할 때만)

사용자가 "이번 달 토론 만들어줘", "○○ 토론 만들어줘"라고 하면 Claude가 아래 순서로 직접 작성한다.
API·예약 작업은 쓰지 않는다 (비용 없음, 구독 사용량만 씀). 자동 실행하지 않는다.

1. `git pull --rebase` 후 `python scripts/build_debate.py --todo` 로 이번 달 토론이 없는 기업 확인
2. 기업마다:
   - `python scripts/build_debate.py --prompt <slug>` 출력(프롬프트 + 데이터 시트)을 읽는다
   - 프롬프트 규칙대로 토론 JSON을 작성한다. 숫자는 데이터 시트에 적힌 값만 그대로 쓴다. 계산해서 새 숫자를 만들지 않는다.
   - `python scripts/build_debate.py --save <slug> <json파일>` — "검증 실패"면 지적된 숫자를 고쳐 다시 저장
3. `python tests/test_debate.py` 통과 확인 후 커밋·푸시 (커밋 메시지: "기업 토론 YYYY-MM: 기업명…")

토큰 사용량(대략): 기업 1곳당 데이터 시트 읽기 + 작성 + 검사로 약 1.5만 토큰. 64곳 전부는 한 세션에 무리이므로 10곳 안팎씩 나눠 한다.

- 프롬프트 원문: `prompts/debate_council.md` (사용자 작성본. 고치면 다음 작성부터 반영)
- 화면: 대시보드 '기업 토론' 탭, 발화자 캐릭터는 `assets/debate-cast.json` (현재 임시)
- 결과 파일: `companies/<slug>/data/debate/<YYYY-MM>.json`, 목록 `companies/debate_index.json`
